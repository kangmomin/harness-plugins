- **변경**: +49 / −18, 파일 3개 (문서·매니페스트만, 실행 코드 없음)

## TL;DR

1. 플릿 준수도 감사(9개 서비스 × 7개 차원)에서 발견된 **go-conventions 정본과 minmos 컨벤션 스킬의 괴리 5건 중 4건을 정본 수용**으로 해소.
2. **UoW 명시적 Rollback 1건만 로컬 예외로 존치** — `[Local Exception]` 블록으로 결정 근거·결정자·재발 시 대응 명시 (사용자 결정, 2026-07-23).
3. `default-conventions-mm` 에 **§0 정본(SSOT) 우선 원칙 신설** — 이후 어떤 충돌이 생겨도 문서 스스로 우선순위를 선언.
4. 플러그인 버전 v1.10.0 → **v1.10.1**.

## 왜 바꿨는가

`convention-check-mm` 은 설정 파일이 없으면 default-conventions + pagenation 을 기본 적용한다. 종전 내용대로면 **SSOT 를 정확히 따르는 레포(예: OCS 의 `defer Rollback`, 4-tuple `GetAllCursor`)를 위반으로 오판**하는 구조적 위험이 있었다. 정본-로컬 우선순위를 명시하고 충돌 조항을 정렬해 이 위험을 제거한다.

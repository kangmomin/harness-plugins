# common:how-to-use 명세

스킬 파일은 이 명세에서 다시 만들 수 있어야 한다. 모델이나 호스트가 바뀌면 SKILL.md 를 고치고, 이 명세와 사례로 다시 시험한다.

## 목표
현재 세션에 설치된 harness 플러그인의 스킬 목록과 호출 방법을 안내한다.

## 결과물
- 플러그인별 `스킬 | 실제 호출명 | 설명` 표

## 필수 행동
- 세션이 실제로 제공한 스킬 metadata 만 쓴다.
- 플래그가 없으면 묻지 않고 전체를 안내한다.

## 금지 행동
- 설치되지 않은 스킬이나 추측한 호출명을 쓰지 않는다.
- 스킬을 실행하거나 설치하지 않는다.

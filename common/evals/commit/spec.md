# common:commit 명세

스킬 파일은 이 명세에서 다시 만들 수 있어야 한다. 모델이나 호스트가 바뀌면 SKILL.md 를 고치고, 이 명세와 사례로 다시 시험한다.

## 목표
현재 변경을 논리 단위로 나누고, 단위마다 이 저장소 규칙의 메시지로 커밋한다.

## 결과물
- 단위별 커밋 (커밋 1개 = 책임 1개)
- `Prefix: 한국어 설명` 형식의 메시지

## 필수 행동
- Prefix 는 `Add, Fix, Del, Refactor, Doc, Test, Chore, WIP` 중 하나를 쓴다.
- 그룹의 명시 경로만 스테이징한다.
- 커밋 뒤 실제 커밋 범위와 계획한 그룹을 대조한다.

## 금지 행동
- `.env` 등 민감한 파일을 커밋하지 않는다.
- 사용자의 부분 스테이징을 전체 파일로 덮지 않는다.
- Claude Code 서명을 남기지 않는다.
